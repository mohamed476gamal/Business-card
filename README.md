# Mohamed Business Card

A personal business card built with HTML and CSS as part of my frontend development learning journey.

## Features

- Personal profile image
- Custom color palette
- Responsive flexbox layout
- Rounded corners
- Box shadow
- Hover effects
- Smooth transitions
- Entry animation
- Web-safe font

## Built With

- HTML
- CSS

## What I Learned

While building this project, I practiced:

- Structuring a simple page with HTML
- Using CSS classes
- Flexbox layout
- `gap`
- `align-items`
- `border-radius`
- `box-shadow`
- `hover:`
- `transition`
- `transform`
- `@keyframes`
- Web-safe fonts
- Working with images and relative paths
